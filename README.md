# Realtime Image Search App 🔍🖼️

A clean and responsive realtime image search web app built using **HTML, CSS, and JavaScript**, powered by the **Pixabay API**.

## 🚀 Features
- Realtime image search (with debouncing)
- Clean and modern UI
- Smooth animations
- Responsive image grid
- Load more results
- Free image source (Pixabay)

## 🛠️ Tech Stack
- HTML
- CSS (Animations & Responsive Design)
- JavaScript (Fetch API, DOM manipulation)
- Pixabay API
